## ♥ Sobre o projeto

O **Texto no Ar** é um projeto desenvolvido na disciplina de **Sistemas Digitais**, da Universidade Federal de São Carlos (UFSCar).

A proposta consiste em utilizar uma única coluna de LEDs de uma placa FPGA para formar uma imagem no espaço, por meio da apresentação sequencial de padrões luminosos.

Neste projeto, escolhemos representar um **coração**, utilizando combinações de bits armazenadas em memória.

O resultado é baseado no princípio da **persistência da visão**: ao movimentar a placa enquanto os LEDs são acionados em uma sequência controlada, é possível perceber a formação de uma imagem no ar.

## ❤️ Como funciona?

O projeto utiliza uma sequência de padrões binários para construir a figura escolhida.

<div align="center">

| Etapa | Funcionamento |
|:---:|---|
| ❤️ 01 | **Memória:** armazenamento dos padrões que formam o coração. |
| 02 | **Leitura:** acesso sequencial aos endereços da memória. |
| 03 | **LEDs:** acionamento de acordo com os bits armazenados. |
| 04 | **Temporização:** controle do intervalo entre os padrões. |
| 05 | **Movimento:** combinação entre a sequência luminosa e o movimento da placa. |

</div>

Cada combinação de bits representa uma configuração dos LEDs. Quando os padrões são apresentados na ordem correta e a placa é movimentada, a figura pode ser percebida visualmente.

## ♥ A figura: um coração em pixels

A imagem escolhida foi um coração, representado por diferentes combinações de LEDs.

A escolha permite explorar a construção de imagens utilizando informações binárias, demonstrando como uma sequência de dados pode produzir um resultado visual.
